# 🎓 Student Performance Prediction - Learning ML Project

This repository contains a simple **end-to-end Machine Learning project** built while learning **Machine Learning and MLOps concepts**. The project predicts a student's **Math Score** based on various academic and demographic features using regression models.

## 🚀 What I Learned

* Data Ingestion
* Data Preprocessing
* Feature Engineering
* Model Training & Evaluation
* Model Serialization (Pickle)
* Building a Prediction Pipeline
* Deploying a simple web app using Flask

## 🛠️ Tech Stack

* Python
* Scikit-learn
* Pandas
* NumPy
* CatBoost
* Flask

## 📂 Project Structure

```text
MLProject/

```

## ▶️ Run Locally

```bash
git clone https://github.com/Ayanonmyous/MLProject.git

cd MLProject

pip install -r requirements.txt

python app.py
```

Then open:

```
http://127.0.0.1:5000
```
